# AgroRadar AI · MVP v0.5 — Satellite GIS + Weather

Рабочий учебный прототип для конкурса IT-спринт по кейсу Русагро. Карта отображает **настоящие спутниковые снимки Sentinel‑2**, а стартовые 4 поля являются вымышленными демонстрационными объектами. Не путайте эти два типа данных.

## Запуск Windows 10/11

Перед обновлением сделайте коммит текущего проекта через GitHub Desktop и распакуйте содержимое этой папки в корень репозитория с заменой файлов. Файлы `frontend/.env.local` и `backend/.env` не входят в архив и не должны перезаписываться.

В терминале №1:

```powershell
cd "C:\Users\domar\AgroRadar-AI\backend"
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

В терминале №2:

```powershell
cd "C:\Users\domar\AgroRadar-AI\frontend"
npm.cmd install
npm.cmd run dev
```

Откройте http://localhost:5173.

Если `.venv` ещё не создан: `python -m venv .venv` в папке backend.

## Настоящая погода OpenWeather

Создайте файл `backend/.env`, если его нет (пример — `.env.example`), укажите:

```env
OPENWEATHER_API_KEY=ВАШ_КЛЮЧ
```

Перезапустите backend. Без ключа приложение использует **демонстрационную** погоду и демонстрационный прогноз. OpenWeather запрашивается backend, ключ в браузер не отправляется. Отдельный ключ для карты **не нужен**.

## Карта и контуры

* Спутник Sentinel‑2/EOxCloudless: сравнение 2024 и 2016 годов, Leaflet, WGS84, показ координат и масштабов, цветные риски, выбор полей.
* Реальные границы полей можно нарисовать на карте или импортировать через GeoJSON. Сохраняются на сервере, площадь и центр пересчитываются.
* Доступ к спутниковой подложке **онлайн** (без внешнего ключа). Если интернет отсутствует, полигоны остаются на экране, но снимки не загрузятся.
* Присутствует обязательная атрибуция EOxCloudless внизу карты. Лицензия слоя 2024 — CC BY-NC-SA 4.0, только некоммерческое использование. Для внедрения в производство необходимо лицензирование.

Подробно: [MAP_GUIDE.md](MAP_GUIDE.md)

## API и тесты

- GET `/api/health`, `/api/dashboard`, `/api/fields`, `/api/fields.geojson`
- PUT `/api/fields/{field_id}/geometry` — сохранить координаты кольца `[lon,lat]`
- DELETE `/api/fields/{field_id}/geometry` — сбросить контур
- Документация: http://127.0.0.1:8000/docs

Для локальных тестов (нужен `pytest`):

```powershell
cd backend
.\.venv\Scripts\python.exe -m pip install pytest
.\.venv\Scripts\python.exe -m pytest tests -q
```

## Статус достоверности

Настоящие: подложка Sentinel‑2 (но снимки архивные); географическая привязка GeoJSON; площадь вручную обведённых участков — приближённый расчёт; погодные данные при подключённом OpenWeather API.

Демонстрационные: названия и посевы четырёх полей, изначальные их центры/контуры и погодные измерения без API-ключа. Риски — простое пороговое правило, **не валидированная вероятность потерь урожая**.
