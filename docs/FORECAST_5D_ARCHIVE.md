# Пятидневный прогноз и архив OpenWeather

## Расчёты

В разделе «Обзор» добавлены **пять последовательных периодов по 24 часа**
от момента получения прогноза (это не календарные дни по местному времени).
Источник — тот же OpenWeather 5 Day / 3 Hour Forecast, дополнительного API не требуется.

Каждые сутки обрабатываются **отдельно** четырьмя правилами AgroRisk Engine 3.0:
похолодание, осадки, ветер, сухая жара. Пороги суточных осадков применяются
к сумме только за свой период, а не к пятидневной сумме. Видны прогнозные
минимальная/максимальная температура, сумма дождя, число трёхчасовых интервалов,
уровень риска, причины предупреждения и недостаток данных.

Существующие 24-часовые API и модуль прогноза остаются совместимыми.
Новый endpoint: `GET /api/fields/1/five-day-forecast`.

Без действительного OpenWeather API-ключа показываются синтетические
данные с пометкой ДЕМО. Если данных для периода нет, выводится «Нет данных».

## SQLite-архив предыдущих прогнозов

Серверная сводка сохраняет дневной снимок в
`backend/data/monitoring.sqlite3`, таблица `forecast_archives`:
идентификатор поля, UTC-дата, время сохранения, источник, текущая
температура и JSON полного пятидневного прогноза (включая интервалы).

Для каждого поля сохраняется **одна актуализируемая запись на UTC-день**:
при следующем открытии сводки в этот день она обновляется.
Записи старше 45 дней удаляются при следующем успешном сохранении для поля.
Просмотр: выпадающий список «Снимок прогноза» на главной странице.
API просмотра: `GET /api/operations/fields/1/forecast-archive?limit=30`.

ДЕМО-данные и недоступные прогнозы **не записываются** как живые.
Прогнозы прошедших дней, когда приложение не открывали,
задним числом не восстанавливаются. Существующая история оценок рисков
в SQLite сохраняется и не меняет формат.

**Архив хранит прогнозы, которые были получены в предыдущие дни,
а не фактические измерения погоды в те дни.**
Прогнозные значения не измеряются метеостанциями на конкретном поле.
Надёжность дальней части прогноза ниже, а пороги AgroRisk учебные.
