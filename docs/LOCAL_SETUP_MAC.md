# Локальный запуск AgroRadar AI на macOS и Wi‑Fi

## Зависимости

Установите Python 3.12 и Node.js 22 или 24 с npm. Откройте Terminal в каталоге проекта и подготовьте зависимости.

```sh
cd backend
python3.12 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
cd ../frontend
npm ci
cd ..
```

Для обычного просмотра на этом Mac запускайте backend на `127.0.0.1:8000` и Vite на `127.0.0.1:5173`. Для демонстрации с телефона запустите `./DEMO_WIFI.command`. Скрипт собирает интерфейс, открывает страницу подключения и выводит QR-код для каждого доступного адреса локальной сети. Остановить сервер можно через Ctrl+C в окне Terminal.

## API-ключи

Ключи необязательны для просмотра демонстрации. Без ключа OpenWeather приложение покажет демонстрационную погоду. Без ключа Яндекс Карт откроется слой OpenStreetMap. Для чата через Wi-Fi нужен ключ DeepSeek. В готовом экспертном приложении для macOS доступен встроенный демодиалог.

| Что | Где получить | Переменная | Файл |
|---|---|---|---|
| Погода OpenWeather | [OpenWeather API](https://openweathermap.org/api), создать API key в личном кабинете | `OPENWEATHER_API_KEY` | `backend/.env` |
| ИИ-помощник DeepSeek | [DeepSeek API keys](https://platform.deepseek.com/api_keys) | `DEEPSEEK_API_KEY` | `backend/.env` |
| Модель DeepSeek (необязательно менять) | Имя модели, доступной в аккаунте DeepSeek | `DEEPSEEK_MODEL` | `backend/.env` |
| Яндекс Карты | [Кабинет разработчика Яндекса](https://developer.tech.yandex.ru/), подключить JavaScript API 2.1 | `VITE_YANDEX_MAPS_API_KEY` | `frontend/.env.local` для запуска из исходников |

При первой настройке создайте отсутствующие файлы `backend/.env` и `frontend/.env.local` по одноимённым образцам `.env.example` из соответствующих каталогов. Готовое экспертное приложение на Mac читает настройки из `~/Library/Application Support/AgroRadar AI Expert/settings.env`. После первого запуска там же появится образец. Для быстрого обзора можно оставить оба файла без ключей. Для браузерного ключа Яндекс Карт укажите допустимый HTTP Referer, включая `127.0.0.1` и LAN-адрес, с которого будете открывать карту. Не отправляйте реальные ключи в чат или GitHub.

`AGRORADAR_AUTO_MONITOR=0` отключает фоновый опрос, `AGRORADAR_MONITOR_BATCH` и `AGRORADAR_MONITOR_INTERVAL_SECONDS` ограничивают его объём и частоту, `AGRORADAR_WATER_CONTEXT=1` включает дополнительный контекст Open-Meteo, `AGRORADAR_SECURE_COOKIES=0` соответствует локальному HTTP. Если `AGRORADAR_ADMIN_PASSWORD` не задан, пароль администратора создаётся в `backend/data/admin_access.txt`.

## Доступ с телефона

Перед Wi‑Fi-запуском подключите Mac и телефон к одной доверенной сети. Подключайтесь с отдельной учётной записью «Наблюдатель». Администратор входит на самом Mac. macOS может спросить, разрешить ли Python принимать входящие подключения. Разрешайте только в доверенной локальной сети. Если используется брандмауэр, добавьте исключение для Python на время демонстрации и удалите его после.

Соединение использует HTTP без шифрования. Не передавайте через публичный или гостевой Wi‑Fi реальные пароли, ключи или конфиденциальные данные полей. Изоляция клиентов в Wi‑Fi может блокировать связь телефона с Mac. В этом случае используйте доверенный хот-спот.
