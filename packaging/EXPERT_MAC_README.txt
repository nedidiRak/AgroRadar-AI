AgroRadar AI 4.0 — ЭКСПЕРТНАЯ ВЕРСИЯ ДЛЯ macOS

1. Выберите архив под свой процессор:
   AppleSilicon — Mac с Apple M1/M2/M3/M4 и более новыми Apple Silicon.
   Intel        — Mac с процессором Intel (x86_64).

2. Дважды щёлкните ZIP, чтобы распаковать его.
   Сначала извлеките ВСЮ папку; не запускайте приложение из ZIP.
   Откройте AgroRadar-Expert.app двойным щелчком.
   Приложение запускает локальный сервер и открывает интерфейс в браузере.
   Если страница не открылась автоматически, попробуйте:
   http://127.0.0.1:18765/

3. Вход в программу:
   Логин:  admin
   Пароль: AgroRadar-Expert!2026

4. Если macOS сообщает «Apple не может проверить разработчика»:
   Откройте Системные настройки > Конфиденциальность и безопасность,
   найдите сообщение об этом приложении и нажмите «Всё равно открыть»
   (Open Anyway). Подтвердите запуск, если доверяете архиву.
   Это неподписанная сертификатом Apple, НЕ нотариально заверенная
   экспертная сборка. Не отключайте Gatekeeper целиком.
   Если правила организации запрещают запуск неподписанного ПО,
   согласуйте установку с её ИТ-администратором.

5. Хранение данных и ключей (вне приложения):
   ~/Library/Application Support/AgroRadar AI Expert/
   При первом запуске здесь появится settings.env.example.
   Чтобы подключить настоящие погодные данные и ИИ, скопируйте
   settings.env.example в settings.env и заполните:
       OPENWEATHER_API_KEY=...
       DEEPSEEK_API_KEY=...
       VITE_YANDEX_MAPS_API_KEY=...
   Для применения изменений завершите приложение и запустите его вновь.
   Не отправляйте файл settings.env кому-либо и не выкладывайте в GitHub.
   Пользовательские поля, настройки и история сохраняются в папке data
   внутри указанной директории, отдельно от .app.

6. Для остановки:
   Закройте приложение AgroRadar-Expert через системный переключатель
   приложений или «Мониторинг системы» (Activity Monitor).
   Закрытие вкладки браузера НЕ обязательно останавливает локальный сервер.

Важные ограничения:
- Не нужны Python, Node.js, npm, Git или отдельная установка библиотек.
- Сервер принимает соединения только на 127.0.0.1; подключение по Wi-Fi
  с других устройств в этом архиве отключено.
- Нет встроенных личных API-ключей автора, его полей и паролей.
- Публичный тестовый пароль пригоден ТОЛЬКО для локальной демонстрации,
  не для реального хозяйства или чувствительных данных.
- Без ключей OpenWeather и DeepSeek приложение использует обозначенные
  демонстрационные данные/ответы, не притворяясь настоящей нейросетью.
- Для онлайн-карт и живой погоды потребуется интернет.
- Яндекс Карты могут требовать разрешить 127.0.0.1 в настройках HTTP Referer.
- Если порт 18765 занят, программа выберет другой свободный порт.
- Для Mac с Apple Silicon скачайте AppleSilicon, для Intel — Intel.
- Копия не сертифицирована Apple, поэтому macOS Gatekeeper может
  предупредить о запуске.
