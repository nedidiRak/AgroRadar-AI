AgroRadar AI 4.0 | ЭКСПЕРТНАЯ ВЕРСИЯ WINDOWS x64
============================================================

ЗАПУСК (Windows 10/11 x64):
  1. Извлеките ВЕСЬ архив в обычную папку.
  2. Дважды щёлкните AgroRadar-Expert.exe.
  3. Откроется браузер. Если браузер не открылся,
     используйте адрес http://127.0.0.1:18765/
     (или тот, который программа покажет в окне).
  4. Логин:  admin
     Пароль: AgroRadar-Expert!2026
  5. Для завершения закройте окно программы или нажмите Ctrl+C.

НЕ ТРЕБУЕТ УСТАНОВКИ:
  Python, Node.js, npm, SQLite и платного ПО.

ЧТО МОЖНО ПРОВЕРИТЬ:
  [x] Создание, изменение и удаление полей с настоящим сохранением
  [x] Геометрия поля; каталог и GeoJSON
  [x] Риски, правила и научные ссылки, сведения о поле
  [x] Центр решений: задания, завершение, результат и журнал
  [x] Отчёты и экспорт данных
  [x] Базовый офлайн-диалог по выбранному полю (ДЕМО, не DeepSeek)
  [x] Настоящий DeepSeek после добавления ключа в settings.env
  [x] OpenWeather после добавления ключа в settings.env
  [x] Яндекс Карты после добавления публичного ключа в settings.env

ПРО ИИ:
  Без ключа DeepSeek доступен ДЕМОНСТРАЦИОННЫЙ сценарий
  диалога по данным поля, а НЕ настоящая нейросеть.
  Настоящий DeepSeek требует работающего интернета и API-ключа.
  То же относится к актуальной погоде OpenWeather.
  Open-Meteo для водного контекста требует интернета.

КЛЮЧИ:
  Положите рядом с программой файл settings.env:
    OPENWEATHER_API_KEY=...
    DEEPSEEK_API_KEY=...
    VITE_YANDEX_MAPS_API_KEY=...

  Автор может запустить ADD_MY_KEYS.cmd, ввести свои ключи и
  создать готовый ZIP для отправки эксперту.
  У Яндекс Карт возможно ограничение HTTP Referer для localhost.

СОХРАНЕНИЕ:
  Новые поля, задания и история находятся в папке data/
  рядом с программой; после перезапуска они остаются.
  Для чистого теста остановите программу и удалите
  только папку data/ в ЭТОЙ копии.

БЕЗОПАСНОСТЬ:
  Программа слушает только 127.0.0.1 на этом компьютере.
  Пароль admin в этой специальной сборке общеизвестен;
  НЕ используйте данный пакет на общем сервере, в интернете
  или для данных реального хозяйства.
  Если добавить ключи в ZIP, их сможет прочитать получатель.
