# AgroRadar AI v1.2 — Calm Workspace

Это обновление **только интерфейса** для работающей версии AgroRadar AI v1.1 / v1.1.1.

## Изменения

- Три отдельных раздела: **Обзор**, **Карта и поля**, **ИИ-агроном**.
- Обзор содержит ключевые показатели, список участков по степени риска, прогноз и переход к ИИ.
- Карта открывается в отдельной рабочей области; список полей и действия изменения/удаления расположены справа.
- Поиск полей по названию или культуре.
- Дополнительные данные и инструменты импорта/экспорта GeoJSON доступны через раскрывающиеся блоки.
- Чат ИИ получает отдельный экран. При переходе между разделами история переписки **сохраняется**, пока не изменено выбранное поле (для другого поля начинается новый диалог).
- Карта монтируется при первом открытии раздела и затем сохраняется между переключениями. Компонент карты из рабочей версии v0.9 **не меняется**.
- Интерфейс адаптирован под узкие экраны.

## Установка

1. В GitHub Desktop создай коммит текущего рабочего состояния, например `Backup before UI v1.2`. Рекомендуется также `Push origin`.
2. Останови frontend сочетанием `Ctrl+C`, если он запущен. Backend останавливать необязательно.
3. Содержимое каталога `frontend/src` из ZIP скопируй в `C:\Users\domar\AgroRadar-AI\frontend\src`:
   - **замени** `main.tsx`;
   - **добавь** `layout-v1.2.css`.
4. Запусти frontend:

   ```powershell
   cd "C:\Users\domar\AgroRadar-AI\frontend"
   npm.cmd run dev
   ```

5. Открой `http://localhost:5173`, обнови сочетанием `Ctrl + F5`.

Новые npm-библиотеки не требуются. Существующие `AiAgronom.tsx`, `AiAgronom.css`, `GeoFieldsMap.tsx`, API-ключи и `backend` остаются нетронутыми.

## Проверка

1. **Обзор:** нажми на поле в списке — прогноз и температуру справа должен показать выбранный участок.
2. **Карта и поля:** приблизь карту, выбери поле в списке, измени его название и проверь, что оно обновилось.
3. Нажми **«Новое поле»** над картой, создай пятый участок; он должен сохраниться в backend. Удалять реальное поле для теста необязательно.
4. Открой **«Дополнительные инструменты GeoJSON»** и убедись, что импорт/экспорт доступны.
5. **ИИ-агроном:** отправь вопрос, переключись на обзор и вернись — история разговора должна остаться.
6. Уменьши ширину окна браузера — навигация должна превратиться в компактную панель сверху.

## Откат

В GitHub Desktop: вкладка History -> открой коммит с предыдущей рабочей версией и восстанови `frontend/src/main.tsx`. Добавленный `frontend/src/layout-v1.2.css` можно удалить. Либо откати новый коммит целиком, если после обновления он уже создан.

## Ограничения проверки

Файлы TSX проверены на синтаксис через TypeScript, CSS — через CSS-парсер, но полноценная сборка Vite и визуальная проверка в браузере недоступны в текущем окружении. Никакие backend API и сторонние ключи не затрагиваются.
