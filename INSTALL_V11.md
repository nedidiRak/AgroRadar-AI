# AgroRadar AI v1.1 — DeepSeek ИИ-агроном

Совместимо с **AgroRadar AI v1.0 Field Manager**. Это *патч*, а не полный проект.
Работающие Яндекс Карты, OpenWeather, GeoJSON и каталог полей сохраняются без изменений.

## Что реализовано

- Панель **ИИ-агроном** под картой и пункт меню слева для перехода к ней.
- Контекст берётся на сервере **для выбранного field_id**: название, культура, описание, площадь,
  геометрия, текущая погода, прогноз OpenWeather и температурный индикатор рисков.
- DeepSeek получает короткие общие справочные заметки из `backend/app/agronomy_knowledge.py`;
  это простая локальная база рекомендаций MVP, **не полноценная проверенная RAG-база**.
- Несколько готовых вопросов, собственный вопрос, история текущего диалога (до 10 сообщений).
- Серверный API-ключ, статусы подключения, понятные ошибки 401/402/429/таймаутов, ограничение 12 запросов/мин по IP.
- Отсутствующий DeepSeek-ключ не ломает карту, поля и OpenWeather.

## Установка (Windows)

1. Сначала сделай резервный коммит в GitHub Desktop — `Backup before DeepSeek v1.1`.
2. **Не удаляй** файлы `backend/.env`, `frontend/.env.local`, папку `backend/data`.
3. Распакуй ZIP и **скопируй содержимое** в корень репозитория, например:
   `C:\Users\domar\AgroRadar-AI`, с заменой совпадающих файлов.
4. Открой файл настроек backend:

```powershell
notepad "C:\Users\domar\AgroRadar-AI\backend\.env"
```

В нём должны быть две строки (каждая на своей строке):

```env
OPENWEATHER_API_KEY=ТВОЙ_СУЩЕСТВУЮЩИЙ_КЛЮЧ_OPENWEATHER
DEEPSEEK_API_KEY=ТВОЙ_КЛЮЧ_DEEPSEEK
DEEPSEEK_MODEL=deepseek-flash
```

**Существующую строку OpenWeather не стирай.** `DEEPSEEK_MODEL` необязателен, по умолчанию `deepseek-flash`.
Нельзя помещать DeepSeek-ключ в `frontend/.env.local`, GitHub или JavaScript.
Ключ создаётся в [личном кабинете DeepSeek](https://platform.deepseek.com/api_keys).
Тарификация зависит от модели и числа токенов; проверь баланс DeepSeek API.

5. Перезапусти backend (он читает `.env` при запуске):

```powershell
cd "C:\Users\domar\AgroRadar-AI\backend"
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

6. Во втором PowerShell запусти frontend (если он уже запущен, можно просто обновить страницу):

```powershell
cd "C:\Users\domar\AgroRadar-AI\frontend"
npm.cmd run dev
```

7. Открой `http://localhost:5173`. В меню слева выбери **ИИ-агроном** либо прокрути страницу под карту.

## Проверка API

- `http://127.0.0.1:8000/api/health` — должен отвечать `status: ok`.
- `http://127.0.0.1:8000/api/ai/status` — ожидается `configured: true`.
  Это означает только что ключ прочитан, **не проверяет его баланс**.
- Для реальной проверки нажми один из готовых вопросов, например «Оцени погодные риски на 24 часа».
- При отсутствии средств на DeepSeek API или неверном ключе появится понятная ошибка, карта продолжит работать.

## Как демонстрировать на защите

1. Выбери поле с заданной культурой и описанием; покажи на карте его геометрию.
2. Обрати внимание на **источник OpenWeather** и на температурный индикатор.
3. Нажми **ИИ-агроном** и задай вопрос «Оцени погодные риски и предложи проверку на месте».
4. Покажи, что помощник приводит причину предупреждения и отличает наблюдения от прогнозов.
5. Выбери другую культуру/поле, покажи, что контекст поменялся. История диалога не переносится между полями.

**Ограничения и безопасность:** это ИИ-помощник, не автономный управляющий агент.
Он **не меняет поля**, **не запускает сельхозтехнику**, не умеет достоверно определять болезни по данным погоды.
Внешний сервис DeepSeek получает координаты, культуру, описание выбранного поля и историю отправленного диалога.
Не вводи персональные или коммерчески конфиденциальные данные без соответствующего разрешения.
Для публичной эксплуатации дополнительно необходимы аутентификация, полноценное ограничение запросов,
многопользовательское хранение диалогов, аудит, верифицированная агрономическая база знаний и оценка качества рекомендаций.

- TSX синтаксически разобран TypeScript компилятором без ошибок.
- Полную React-сборку в данной среде завершить нельзя: недоступен npm registry.
- Живой запрос к DeepSeek не выполнялся без пользовательского ключа.
