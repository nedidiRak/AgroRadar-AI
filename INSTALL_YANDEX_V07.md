# AgroRadar AI — Yandex Maps v0.7 (патч к v0.5)

Подготовлена замена карты Sentinel-2 на Яндекс Карты JavaScript API 2.1 с режимами Спутник, Гибрид, Схема. Backend, OpenWeather и сохранение контуров не меняются. Поля исходно демонстрационные.

## Установка на Windows

1. Сделайте коммит текущей версии в GitHub Desktop.
2. Распакуйте ZIP, скопируйте папку `frontend` из ZIP **в корень репозитория AgroRadar-AI**, согласившись на замену файлов. Не стирайте другие файлы: нужен именно режим слияния/замены совпадающих файлов.
3. Ваш `frontend/.env.local` **не перезаписывается**. Убедитесь, что в нём есть строка:

```env
VITE_YANDEX_MAPS_API_KEY=ВАШ_АКТИВНЫЙ_КЛЮЧ
```

Не копируйте ключ в README или в Git. Убедитесь, что JavaScript API активен, а HTTP Referer в настройках ключа разрешает `localhost`.
4. Перезапустите фронтенд (`Ctrl+C`, затем `npm.cmd run dev`):

```powershell
cd "C:\Users\domar\AgroRadar-AI\frontend"
npm.cmd run dev
```

Backend, как обычно, запускается отдельно (порт 8000).
5. Откройте `http://localhost:5173/`. Проверьте переключатели Спутник/Гибрид/Схема, выбор поля, кнопки «Все поля», «Контуры», «Обвести поле».

## Диагностика

API 3.0 ранее давал ответ 200, но **2.1 — другой адрес** и должен отдельно пройти проверку в браузере. При пустой карте откройте `F12` → Network → запрос `api-maps.yandex.ru/2.1/`, проверьте его статус. Если 403, сохраните статус и текст ошибки, не размещая ключ в скриншоте. При отображении карты, но отсутствии снимков, проверьте связанные запросы Яндекс Карт и блокировщики рекламы/сетевые ограничения.

Загрузка карты через интернет обязательна. Логотипы и указания правообладателей Яндекса остаются на карте. Первоначальные 4 поля и их примерные границы — учебные данные, а не фактические контуры сельхозпредприятия. Реальные геометрии можно обвести на карте или загрузить в GeoJSON.

Новый компонент использует только штатный JavaScript API 2.1; дополнительные npm-пакеты не требуются. Leaflet остаётся в зависимостях прежнего проекта, но новой картой не используется.
